# 🎂 Birthday Surprise Website

A beautiful, interactive, and responsive web application built to celebrate a special birthday! 
This project features glassmorphism design, custom animations, interactive scratch-off cards, and a fully functional 3D virtual cake simulator.

## ✨ Features

- **Starry Night Atmosphere:** Beautiful glowing stars and shooting star animations in the background.
- **Virtual Gift Box:** A suspenseful unboxing experience.
- **Scratch Card Surprise:** An HTML5 Canvas-based interactive scratch card that reveals the main gift.
- **Virtual Cake Simulator:** Blow out the candles with a tap, and use the knife to cut out a perfect slice of cake!
- **Polaroid Memory Wall:** A responsive CSS grid displaying beautifully styled polaroid photos.
- **Audio Transitions:** Epic countdown riser music seamlessly transitioning into the main birthday soundtrack.
- **100% Mobile Responsive:** Optimized to look perfect on any phone screen.

## 🚀 How to Run Locally

You don't need any complex servers to run this project! 
Simply double-click the `index.html` file to open it in your browser, or if you use VS Code, use the **Live Server** extension to host it locally.

## 🛠️ Built With
- HTML5
- Vanilla CSS3 (Custom Variables, Keyframes, Flexbox, CSS Grid)
- Vanilla JavaScript (DOM manipulation, Canvas API)
